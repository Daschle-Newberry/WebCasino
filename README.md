## Web Casino

Web Casino is a frontend-only REACT project created by Eli, Ognian, Diego, and Dash for CS220.

## How to Build

1. Get access to and clone the repo
```commandline
git clone https://github.com/Daschle-Newberry/WebCasino
```
2. Install dependencies
```commandline
npm update
```
3. Start the web server
```commandline
npm start
```

## Games

- Baccarat
- Blackjack
- Roulette
- Slots
